# Collabify — Simple Vanilla Demo

This is a minimal, framework-free version of the Collabify demo built with plain HTML, CSS, and JavaScript.

Files:
- `index.html` — Home page and overview
- `browse.html` — Browse mock creators
- `profiles.html` — Edit your local profile, status, and schedule (stored in your browser's localStorage)
- `styles.css` — Basic styling
- `app.js` — Client-side logic and mock data

How to preview
1. Open `index.html` in your browser (double-click the file). This works for simple demos.
2. (Recommended) Use VS Code Live Server extension to serve files on `http://127.0.0.1:5500` or similar.

Notes
- All data is stored locally in your browser (localStorage). No server or database required for this demo.
- You can edit the HTML/CSS/JS files directly.

Next steps (suggestions):
- Replace mock data with a backend when ready
- Add persistent authentication and database (Prisma/NextAuth) if you want a full-stack app

Enjoy editing!
